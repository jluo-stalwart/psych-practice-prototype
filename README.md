# Psychiatry practice prototype

A clickable prototype of a psychiatry practice system: Home, Schedule, Patients, Visits, Inbox and Tasks, and the patient's intake as a phone chat.

Open it at https://jluo-stalwart.github.io/psych-practice-prototype/

Everything in it is made up: the clinic, the patients and the visits. Nothing is sent anywhere. Each visitor's changes stay in their own browser, and "Reset demo" in the top bar puts everything back.

The AI buttons only work in the claude.ai copy of the prototype. Here they offer the prompt to copy instead, and the demo patients' example notes and summaries still work. The record button plays a made-up session.

`index.html` is the whole prototype. It is built from separate source files kept elsewhere, so change those rather than this file.
